# Описание проекта: Голосовой ассистент в Telegram

## 1. Общая задача
Создать Telegram-бота, который:
1.  Принимает голосовые сообщения от пользователя в группе Telegram.
2.  Транскрибирует аудио в текст с помощью API OpenAI Whisper.
3.  Отправляет транскрибированный текст мне (Gemini) через интерфейс командной строки.
4.  Получает мой текстовый ответ.
5.  Отправляет мой ответ обратно в чат Telegram.

## 2. Технический стек
- **Язык:** Python
- **Библиотеки:** `python-telegram-bot`, `openai`, `python-dotenv`
- **Ключи API:** Управляются через файл `.env`.

## 3. Текущий прогресс
- **Создана структура проекта:** Настроены файлы `.env` и `telegram_bot.py`.
- **Реализована логика:** В `telegram_bot.py` добавлена функция для скачивания голосовых сообщений и их транскрибации через OpenAI Whisper.
- **Проблема:** Возникает ошибка при отправке голосового сообщения в группу. Бот не отвечает.
- **Попытка отладки:** Проверили запущенные процессы, но не смогли определить причину без логов.

## 4. Следующие шаги (с чего продолжить)
1.  **Остановить все "блуждающие" процессы Python**, чтобы избежать конфликтов.
2.  **Запустить бота в интерактивном режиме** (не в фоновом), чтобы видеть все логи и ошибки в реальном времени: `python telegram_bot.py`.
3.  **Отправить тестовое голосовое сообщение** в группу Telegram, чтобы воспроизвести ошибку.
4.  **Проанализировать вывод в консоли**, чтобы найти причину сбоя.
5.  **Исправить ошибку** на основе полученной информации.
